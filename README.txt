ОТКРЫТЬ
Распакуйте весь архив. Откройте index.html двойным щелчком.
Все файлы должны лежать вместе в одной папке.
Программы и установка зависимостей не нужны.

ПЕРЕД СДАЧЕЙ
1. Откройте DOM.html, нажмите F12 и выберите Console.
2. По очереди введите три команды, написанные на странице, и нажмите Enter.
3. Сделайте настоящий скриншот, чтобы были видны страница и результаты команд.
4. Сохраните его как dom-console.png.
5. В DOM.html уберите комментарий вокруг тега img для этого скриншота и инструкцию перед ним. Или пришлите скриншот мне для вставки.
6. Опубликуйте все файлы сайта на GitHub Pages и проверьте их по полученной ссылке.

ЧТО ГДЕ
5 информационных страниц: index.html, info.html, gallery.html, table.html, materials.html.
form.html — две формы, все обязательные типы полей и значения по умолчанию.
passport.html — учебный макет и изменение текста кнопкой.
DOM.html — тот же макет и инструкции получения данных через консоль.
task.html — задача 1008 и отправка условия, данных и результата.
big_img.html — картинка в области 600 x 400 по центру; пропорции сохранены.
Общее меню — текстовые ссылки, графическая ссылка на главную, внешняя ссылка, ссылка на фрагмент, выделение текущей страницы.

ФОРМЫ
Отправка GET на https://httpbin.org/get: сервер показывает полученные параметры.
Это учебная демонстрация; заявки не сохраняются. Нужен интернет и доступность httpbin.org.
Не вводите настоящий пароль или частные контакты. Поле пароля содержит тестовое значение.
Отдельная серверная программа для этого задания здесь не используется.

ПАСПОРТ
Имя и дата рождения — данные автора; фото условное; остальные данные вымышлены.
Год 2008 написан цифрами и при транслитерации не меняется.

ЗАДАЧА
V1 = A^3, V2 = pi*R^2*H.
Для первой нужно M >= V1; для второй M >= V2;
для обеих одновременно M >= V1 + V2.
Если M хватает на каждую по отдельности, это ещё не означает, что хватит на обе сразу.
