КАК ОТКРЫТЬ И ИЗМЕНИТЬ САЙТ

Все файлы лежат в одной папке. Откройте index.html в браузере.
Для редактирования откройте любой .html в VS Code или Блокноте.
Меняйте текст между тегами. Не меняйте значения id, name, href, src, если не хотите изменить работу ссылок и скриптов.
Меню повторяется в каждом HTML-файле: его изменения нужно повторить на всех страницах.

СТРАНИЦЫ
index.html — только меню.
info.html — определения и списки.
gallery.html — картинки и подписи.
table.html — таблица.
materials.html — короткие материалы.
form.html — две формы.
passport.html — паспорт и переключение текста.
DOM.html — паспорт для считывания из DOM.
task.html — задача 1008.
big_img.html — большая картинка.
style.css — минимальное оформление.
passport.js, task.js — код кнопок.

ЧТО ОСТАЛОСЬ ДЛЯ КРИТЕРИЕВ
Настоящий скриншот консоли, который требуется в задании, пока НЕ вставлен.
1. Откройте DOM.html в браузере. Нажмите F12, вкладка Console.
2. По очереди выполните:
document.getElementById('surname').innerText
document.getElementById('first-name').innerText
document.getElementById('birth-year').innerText
3. Должно получиться: Табаков, Артём, 2008.
4. Сделайте скриншот страницы с консолью и сохраните рядом с HTML как dom-console.png.
5. В DOM.html удалите комментарий перед тегом img и после него, чтобы тег стал обычным HTML. Или пришлите мне скриншот для вставки.

ЗАГРУЗКА
Загрузите все файлы из этой папки в корень своего репозитория и нажмите Commit changes.
Настройки GitHub Pages менять не надо. Архив ZIP в репозиторий не загружайте.

КРИТЕРИИ
4 информационные страницы: info, gallery, table, materials.
Общее меню: текущая страница выделена; есть текстовые ссылки, картинка-ссылка в текущем окне, внешняя ссылка в новом окне и ссылка на фрагмент.
Внутренние переходы и возврат к началу — на информационных страницах.
Все три вида списков — info.html.
Картинки с подписями и миниатюра шириной 100 — gallery.html.
Область большой картинки 600 x 400, по центру; пропорции изображения сохранены.
Фоновое изображение, картинка в ячейке и ссылка — table.html.
Контактная форма: фамилия, имя, группа, телефон, email, дата.
Тематическая форма: text, number, radio, checkbox, date, password, hidden и значения по умолчанию.
Формы отправляют GET-запрос на httpbin.org/get, сервер показывает параметры. Это учебная отправка, без сохранения заявок. Используйте тестовые данные и тестовый пароль.
Паспорт разделён на два блока страниц. Фото условное, кроме имени и даты рождения данные вымышлены.
Год 2008 записан цифрами и остаётся тем же при переключении алфавита, как в примере.
Задача проверяет заполнение каждой ёмкости отдельно и обеих одновременно: M >= A^3 + pi*R^2*H. При отправке результат пересчитывается.

Проверены локальные ссылки и вычисления. Визуальная проверка в браузере остаётся за пользователем.
